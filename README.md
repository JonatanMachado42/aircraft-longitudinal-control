# Aircraft Longitudinal Modeling

Model and simulation of the longitudinal dynamics of a aircraft using MATLAB. 

## Development Roadmap

### 1. Mathematical Modeling

- [x] Derive the steady-state equations for cruise flight.
- [ ] Determine the optimal angle of attack for cruise conditions.

### 2. Open-Loop Analysis

- [ ] Implement the aircraft's open-loop dynamic model.
- [ ] Perform step-response simulations involving thrust and pitch angle (θ).
- [ ] Analyze the system's dynamic response and stability.

### 3. Closed-Loop Control

- [ ] Design and implement a single-variable feedback controller.
- [ ] Evaluate closed-loop stability and transient response.

### 4. Advanced Control (Stretch Goal)

- [ ] Develop a decoupled multivariable control strategy.
- [ ] Compare its performance against the single-variable controller.
